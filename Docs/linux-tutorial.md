# BEFORE READING
- Read [README](/README.md) First.

**1.** go to your file explorer, open love2apk and right click and click "open in terminal"

**2.** while in terminal, turn the `builder.sh` into an executable (`chmod +x builder.sh`)

**3.** run `builder.sh` (`./builder.sh`)

you should see your apk in the same love2apk folder
