# BEFORE READING
Read [README](/README.md) First.

APK Name: the title/name of your game

Package Name: basically an id, every app has its own Package Name, you gotta use a format like this
`com.NAME/COMPANY.APPNAME`

App Icon: just drag a `PNG` icon into the text box or put the location of it

LOVE File: you gotta zip your game into a `.love` file and drag it here, read [README](/README.md) to know how to zip it correctly

Orientation: portrait game or landscape, it doesnt work perfectly, you have to put a code reference, read [README](/README.md)

and hit `Build`, once its done you gotta check the love2apk folder that has the `.exe`
you should see your apk file
